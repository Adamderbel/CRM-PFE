Diagramme de Classes Général

Aperçu Global

Ce diagramme représente la structure statique du système CRM ALPHA, incluant les entités principales de gestion de la relation client, des prospections, du catalogue produit et de la sécurité (utilisateurs et rôles).

  • Sécurité : SecUser, SecRole, UserRole.
  • CRM : Prospect, Prospection, LigneProspection, Reclamation, ReclamationHistorique.
  • Référentiels & Intégration CERM : DomaineActivites, StatutProspection, CauseEchec, FamilleProduit, SupportProduit, Societee, ClientCerm, ProduitCerm.
diagramme_classes.puml PlantUML 
@startuml CRM_Class_Diagram

' Paramètres visuels
skinparam class {
    BackgroundColor #ffffff
    BorderColor #7c5cfc
    ArrowColor #4a1fb8
    HeaderBackgroundColor #ece7ff
}

' Package Sécurité
package "Sécurité (sec)" {
    class SecUser {
        + Id : Guid
        + UserName : string
        + Email : string
        + Nom : string
        + Prenom : string
        + PasswordHash : string
        + IsActive : bool
    }

    class SecRole {
        + Id : Guid
        + Name : string
    }

    class UserRole {
        + UserId : Guid
        + RoleId : Guid
    }
}

' Package CRM
package "Relation Client (crm)" {
    class Prospect {
        + Id : Guid
        + Nom : string
        + Prenom : string
        + Email : string
        + Telephone : string
        + Source : string
        + DateCreation : DateTime
        + Notes : string
    }

    class Prospection {
        + Id : Guid
        + DateDebut : DateTime
        + DateFin : DateTime
        + Notes : string
    }

    class LigneProspection {
        + Id : Guid
        + Designation : string
        + DateDemandeOffre : DateTime
        + NumeroDevis : string
        + DateDevis : DateTime
        + NumeroCommande : string
        + DateCommande : DateTime
        + BatEnvoyee : bool
        + DateEnvoiBat : DateTime
        + Concretisee : bool
        + RefArt : string
        + Date : DateTime
    }

    class Reclamation {
        + Id : int
        + Titre : string
        + Description : string
        + Statut : string
        + Priorite : string
        + CreatedAt : DateTime
        + UpdatedAt : DateTime
    }

    class ReclamationHistorique {
        + Id : int
        + Action : string
        + DateAction : DateTime
    }
}

' Package Référentiels / Commun
package "Référentiels & Intégration CERM (comm)" {
    class DomaineActivites {
        + Id : int
        + Libelle : string
    }

    class StatutProspection {
        + Id : int
        + Libelle : string
    }

    class CauseEchec {
        + Id : int
        + Libelle : string
    }

    class FamilleProduit {
        + Id : int
        + Libelle : string
    }

    class SupportProduit {
        + Id : int
        + Libelle : string
    }

    class Societee {
        + Id : int
        + RaisonSociale : string
    }

    class ClientCerm {
        + RefClient : int
        + Nom : string
        + LastModifiedDate : DateTime
        + LastSyncDate : DateTime
    }

    class ProduitCerm {
        + RefProduit : int
        + Designation : string
        + LastModifiedDate : DateTime
        + LastSyncDate : DateTime
    }
}

' Relations Sécurité
SecUser "1" -- "*" UserRole
SecRole "1" -- "*" UserRole

' Relations CRM (Associations)
Prospect "*" -- "1" DomaineActivites : appartient à >
Prospection "*" -- "1" Prospect : concerne >
Prospection "*" -- "1" SecUser : gérée par >
Prospection "*" -- "1" StatutProspection : a pour statut >

' Relations Lignes de Prospection (Composition)
Prospection "1" *-- "*" LigneProspection : contient >

' Relations Ligne de Prospection vers Référentiels
LigneProspection "*" -- "1" FamilleProduit
LigneProspection "*" -- "0..1" SupportProduit
LigneProspection "*" -- "0..1" Societee
LigneProspection "*" -- "0..1" StatutProspection
LigneProspection "*" -- "0..1" CauseEchec : échoue suite à >

' Relations Réclamations
Reclamation "1" *-- "*" ReclamationHistorique : possède historique >
Reclamation "*" -- "0..1" ClientCerm : concerne client >
Reclamation "*" -- "0..1" ProduitCerm : concerne produit >
Reclamation "*" -- "1" SecUser : responsable >
ReclamationHistorique "*" -- "1" SecUser : effectuée par >

@enduml
