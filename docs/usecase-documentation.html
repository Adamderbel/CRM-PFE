Acteurs du Système

👑

Administrateur

Super-utilisateur. Gère les comptes (création, rôles), la configuration globale, et a un accès total aux données CRM.

💼

Commercial

Utilisateur principal. Gère ses propres prospects, mène des prospections, crée des lignes de prospection et génère des devis.

03

Diagramme de Cas d'Utilisation Général

Aperçu Global

Ce diagramme représente les grandes fonctionnalités du CRM ALPHA et les interactions principales des acteurs avec le système.

diagramme_general.puml PlantUML 
@startuml CRM_General

' Configuration visuelle
skinparam actorStyle awesome
skinparam usecase {
  BackgroundColor #ece7ff
  BorderColor #7c5cfc
  ArrowColor #4a1fb8
}

' Définition des acteurs
actor "Commercial" as Comm
actor "Administrateur" as Admin

' Frontière du système
package "CRM ALPHA System" {
    
    ' Cas d'utilisation
    usecase "S'authentifier" as UC_Login
    usecase "Gérer son profil" as UC_Profile
    usecase "Gérer les Comptes" as UC_Comptes
    usecase "Gérer les Prospects" as UC_Prospects
    usecase "Gérer les Prospections" as UC_Prospections
    usecase "Consulter le Dashboard" as UC_Dash

    ' Relations Includes (Inclusion)
    UC_Prospects ..> UC_Login : <>
    UC_Prospections ..> UC_Login : <>
    UC_Dash ..> UC_Login : <>
}

' Associations Acteurs -> Cas
Comm --> UC_Login
Comm --> UC_Profile
Comm --> UC_Dash
Comm --> UC_Prospects
Comm --> UC_Prospections

Admin --> UC_Login
Admin --> UC_Profile
Admin --> UC_Dash
Admin --> UC_Comptes

@enduml
04

Diagramme Détaillé : Gestion des Prospects

Raffinement du cas d'utilisation "Gérer les Prospects", montrant les opérations CRUD et les relations d'extension.

prospects_detail.puml PlantUML 
@startuml CRM_Prospects_Detail

left to right direction

actor "Commercial" as Comm

package "Module Prospects" {
    usecase "Gérer les Prospects" as UC_Main
    
    ' Sous-cas (Généralisation de cas d'utilisation)
    usecase "Ajouter un Prospect" as UC_Add
    usecase "Modifier un Prospect" as UC_Edit
    usecase "Consulter un Prospect" as UC_View
    usecase "Supprimer un Prospect" as UC_Del
    
    ' Extensions
    usecase "Assigner Domaine Activité" as UC_Domaine
    usecase "Créer Prospection Initiale" as UC_ProspectionInitiale

    ' Relations de Généralisation (héritage de Use Case)
    UC_Add -up-|> UC_Main
    UC_Edit -up-|> UC_Main
    UC_View -up-|> UC_Main
    UC_Del -up-|> UC_Main

    ' Relations Extend (Extension)
    UC_Domaine ..> UC_Add : <>
    UC_Domaine ..> UC_Edit : <>
    UC_ProspectionInitiale ..> UC_Add : <>\nCondition: Qualification élevée
}

Comm --> UC_Main

@enduml
05

Diagramme Détaillé : Campagnes de Prospection

prospections_detail.puml PlantUML 
@startuml CRM_Prospections_Detail

actor "Commercial" as Comm

package "Module Prospections" {
    usecase "Créer une Campagne" as UC_CreateCamp
    usecase "Gérer Ligne de Prospection" as UC_Ligne
    usecase "Changer Statut" as UC_Status
    usecase "Clôturer (Échec)" as UC_Echec
    usecase "Générer Devis/Commande" as UC_Devis
    
    ' Includes commun
    usecase "Sélectionner Prospect" as UC_SelectProspect

    UC_CreateCamp ..> UC_SelectProspect : <>
    
    ' Extend
    UC_Devis ..> UC_Ligne : <>\nCond: Concrétisée = vrai
    UC_Echec ..> UC_Status : <>\nCond: Statut = Perdu
    
    ' Include for failure
    usecase "Saisir Cause Échec" as UC_Cause
    UC_Echec ..> UC_Cause : <>
}

Comm --> UC_CreateCamp
Comm --> UC_Ligne
Comm --> UC_Status

@enduml
