# CRM Hub

Multi-project CRM system:

- Backend API: [CRM.WebAPI](CRM.WebAPI) (ASP.NET Core / .NET 8)
- Frontend: [CRM.WEB](CRM.WEB) (Angular 21)
- Worker: [CRM.Worker](CRM.Worker) (.NET 8 background sync jobs)
- Shared layers: [CRM.Services](CRM.Services), [CRM.DAL](CRM.DAL), [CRM.Entities](CRM.Entities), [CRM.Database](CRM.Database)
